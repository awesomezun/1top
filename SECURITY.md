# Security reports

Email sjkang89@gmail.com with a minimal reproduction. Do not publish exploit details, credentials, real user logs, or private screenshots in a public issue. Include the affected component/version and whether a user can cross account, device, or session boundaries.

The current preview is not a security-certified or production-capacity-certified release. Public builds must pass Developer ID signing and Apple notarization before the download metadata is enabled. Never suggest disabling OS protections as an installation step.
