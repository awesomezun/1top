# 1top mobile v1.3.1 — active sessions first

Fresh working sessions appear first across all selected computers, followed by waiting, resuming, paused and idle sessions. Offline or stale reports remain at the bottom even if their last status was working. Ties keep their order as live token values change.

The mobile web dashboard follows the same ordering. Android builds use the existing upload signature; iOS remains a development build, not a public store release. Remote focus/pause/resume/CLI termination use the existing outbound relay connection and do not require the phone and computer to share a LAN. Freeform AI instructions and arbitrary shell commands are not implemented in this release.
