# 1top mobile v1.4.0 — instruct an AI session

Working sessions appear first across computers. Session details now include a multiline AI instruction composer, a selected-device/session confirmation and delivery status. Available controls depend on the current input adapter and fresh device state. The computer must remain running and online; a shared LAN is not required.

Instructions pass through the selected relay without being retained in its receipts. The receiving AI tool can retain them and consume tokens. Delivery is never automatically retried after an uncertain result.

Android is provided as signed APK/AAB previews. iOS is a development build; public App Store/TestFlight distribution remains pending.
