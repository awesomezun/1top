# 1top v3.3.0 preview

The context-map panels have been removed from desktop, web, mobile Usage, and session details. The usage-share treemap now fills the available dashboard width. Session, app, tool, and model grouping; rolling time windows; small-area details; and session controls remain available.

The landing page v4.6.0 uses new recordings and metadata focused on sessions and usage. Mobile v1.2.0 also corrects the built-in Codex Pro example to show its reported weekly window only.

Computer-wide CPU, memory, network, and disk cards now appear only in Computer resources. The compact menu-bar summary remains available.

## Downloads

- macOS Apple Silicon: local ad-hoc signature; Developer ID signing and notarization remain pending.
- Windows x64: unsigned preview installer; WebView2 is required.
- Android: signed preview APK in the mobile-v1.2.0 release.
- iOS: device archive and private development export built. TestFlight/App Store distribution and physical-phone login/control validation remain pending.

Local monitoring remains free and does not require login. General managed-remote signup, public pairing, and billing are not open. Preview downloads are not production-signed installer acceptance evidence.
