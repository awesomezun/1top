# 1top 쇼릴 v1.0.0 초안

랜딩 페이지(https://1top.si) v7.0.0에 넣을 약 45초짜리 소개 영상 초안입니다. 랜딩 v7과 같은 녹화 전용 앱과 데모 데이터로 장면을 다시 녹화하고, 한 프레임씩 합성해 한국어·영어·중국어판을 만들었습니다. 커밋과 배포는 하지 않았습니다. 미리보기를 보신 뒤 승인해 주시면 진행합니다.

## 지킨 규칙

- **데모 데이터만 씁니다.** 프로젝트·계정·경로는 지어낸 것입니다(checkout-web, dev@example.com, /Users/demo/... 등). 실제 계정이나 프로젝트 이름은 없습니다.
- **로고는 크게 둡니다.** 첫 장면과 끝 카드에서 마크와 워드마크가 화면 폭의 약 3분의 1을 차지합니다. 워드마크는 사이트 머리글과 같은 글꼴입니다.
- **모션은 아이디어와 이징만 가져왔습니다.** motion-reference.takayustudio.jp의 클립 리빌, 줄 마스크, 글자 풀림, easeOutQuart·easeInOutCubic을 썼고, 코드는 가져오지 않았습니다.
- **토큰 속도는 tokens/시간입니다.** 선택한 기간의 평균입니다.
- **덮어쓰지 않았습니다.** 쇼릴 파일은 새 이름(`showreel-v1.0.0-<언어>.*`)이고, 녹화 원본과 중간 파일은 `build/showreel_v1.0.0/`에만 있습니다.

## 확인한 것

- 세 언어 모두 1,350프레임(45초 × 30fps), 1920×1080입니다.
- 앞뒤 프레임과 따로 튀는 프레임이 없습니다. ⑥ 장면의 휴대폰 화면은 모든 프레임에서 그려져 있습니다.
- 첫 프레임과 마지막 프레임이 같습니다. 반복 재생할 때 끊기지 않습니다.
- 영어·중국어판의 자막과 화면은 그 언어입니다. ⑦ 장면의 한국어는 언어 버튼이 한국어를 거쳐 가는 순간뿐입니다.
- 모든 화면을 같은 데모 시각(`demoNow` 1800000000)으로 찍었습니다. 데스크톱 대시보드, 맥 메뉴 막대 패널, 윈도우 트레이, 웹 /app, iPhone, Android가 같은 계정 한도(61% · 33% · 71% · 18%)를 보여 줍니다. 이 맥만 보는 대시보드와 패널은 108M tokens/시간·세션 12개입니다. 모든 컴퓨터를 보는 웹과 휴대폰은 127M tokens/시간·세션 21개입니다.

## 랜딩 v7 안의 자리

**권장: 히어로 모션 다음, 01–06 목차 앞에 '45초 둘러보기' 띠를 둡니다.** 모형은 `placement-{ko,en,zh}.jpg`입니다.
- 히어로 문구와 히어로 모션은 그대로 두고, 그 아래에서 01–06 장면을 미리 한 번에 보여 주는 역할입니다. 히어로 문구 바로 아래에 두면 히어로 모션을 밀어내고 같은 제목이 연달아 보여서 이 자리를 골랐습니다.
- 영상은 화면에 들어올 때 무음으로 재생하고, 나가면 멈춥니다. `preload="none"`이라서 내리기 전에는 받지 않습니다.
- 재생·일시정지 버튼을 둡니다. 5초가 넘게 움직이는 영상에는 멈출 방법이 있어야 합니다(WCAG 2.2.2).
- 동작 줄이기 설정에서는 자동 재생하지 않고 포스터와 재생 버튼만 보여 줍니다.
- 페이지 언어에 맞는 판을 고릅니다. WebM을 먼저 두고 MP4를 대신 받게 합니다.
- 휴대폰 폭(390px)에서는 영상이 약 358px로 줄어서 제목은 읽히지만 작은 설명 줄은 읽기 어렵습니다. 휴대폰에서는 누르면 전체 화면으로 재생하게 하거나, 나중에 세로(9:16)판을 따로 만드는 방법이 있습니다.

**대안**
- 히어로의 'v… · 세션 대화…' 알림 옆에 '▶ 45초 영상' 버튼을 두고 누르면 크게 재생합니다. 페이지 무게는 가장 가볍지만 보는 사람이 적습니다.
- 다운로드 영역 바로 위에 요약으로 둡니다. 내려받기 직전에 한 번 더 정리해 주지만, 처음 오는 사람은 거기까지 내려가야 봅니다.
