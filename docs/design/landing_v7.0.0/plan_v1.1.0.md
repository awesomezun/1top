## 3. 미디어

- **위치**: 모두 `site/public/media/v7.0.0/`에 둡니다. `v6.0.0` 등 예전 폴더는 건드리지 않습니다.
- **녹화 스크립트**: `scripts/showcase_v6.0.0/`을 `scripts/showcase_v7.0.0/`으로 복사해 고칩니다.
  - 녹화 전용 앱은 프론트엔드가 '데모 준비됨'을 보낸 커밋에서 빌드합니다.
  - 합성 서버는 `scripts/demo-state.mjs`가 만든 `/api/state`만 응답합니다.
  - 창만 녹화하는 방식(ScreenCaptureKit)과 인코딩(H.264, 24fps)은 v6.0.0과 같습니다.
- **윈도우 퀵뷰**: `agent/onetop/dist/quick.html`을 같은 합성 서버로 띄워 패널 크기로 캡처합니다. 캡션에는 "Windows 트레이 퀵뷰 화면"이라고만 적고, 실제 Windows 창에서 찍은 것처럼 꾸미지 않습니다.
- **휴대폰**: iOS 시뮬레이터와 Android 에뮬레이터를 데모 모드로 켜서 찍습니다. 찍기 직전에 켜고, 찍자마자 끕니다. CPU를 많이 써서 계속 켜 두지 않습니다.
- **언어**: 맥 패널도 이제 3개 언어를 지원하므로 모든 장면을 `-ko`, `-en`, `-zh`로 찍습니다.
- **개인정보**: 실제 계정과 프로젝트 이름은 쓰지 않습니다. 계정은 `example.com`, 프로젝트는 지어낸 이름만 씁니다. 녹화가 끝나면 장면마다 표에 보인 값을 기록하고, 프레임을 눈으로 확인합니다.
- **공유 카드**: 공유 카드(og:image)를 새로 만들면 1top 로고를 크게 둡니다. 여백으로 구분하고 로고를 줄이지 않습니다.

- 참고 사이트(motion-reference.takayustudio.jp)에서는 모션 이름, 타이밍, 표준 이징만 가져옵니다. 코드는 복제하지 않습니다.

## 5. 버전과 파일

- 사이트 버전은 7.0.0입니다. 바꾸는 파일의 예전 내용은 `site/archive/`의 버전 폴더에 보관합니다.
- `landing.js`: 프론트엔드가 이 파일만 동결을 풀어 주었습니다. 휴대폰 첫 화면 문구 띄어쓰기는 이미 고쳤습니다(아래 6).
- `landing-v6.css`와 `main.js`는 아직 동결 목록(`frontend-freeze_v1.16.0.sha256`)에 있습니다.
  - 새 스타일은 새 파일 `landing-v7.css`에 넣고, 이 파일을 `landing.js`에서 불러옵니다.
  - 랜딩의 언어 버튼과 번역 함수 `t`는 `main.js`에 있어서, 중국어 부분은 프론트엔드에 넘깁니다(아래 중국어 항목).
- `hero-motion.js`는 동결 대상이 아닙니다. 히어로 모션 v3.1.0으로 올려 새 패널 이미지와 새 데모 숫자를 쓰고, 자막에 중국어를 더합니다.

### 중국어(간체)

- **문구 작성**:
  - `landing.js`의 모든 문구는 `t(en, ko, zh)`처럼 세 번째 인자로 중국어를 받습니다.
  - 용어는 앱 대시보드의 중국어(`agent/onetop/dist/i18n.js`)와 맞춥니다. 예를 들어 소진 속도, 주간 한도, 토큰 흐름, 사용량 맵을 앱과 같은 말로 씁니다.
- **프론트엔드에 요청할 `main.js` 수정**:
  1. `t(en, ko, zh)`가 세 번째 인자를 받게 합니다. 중국어가 없으면 영어를 보여 줍니다. 이렇게 하면 아직 번역하지 않은 설정·연결 화면은 지금처럼 영어로 남습니다.
  2. 중국어를 고르면 랜딩이 중국어로 보이게 합니다. 지금은 영어로 보입니다. 문서 언어는 `zh-CN`입니다.
  3. 1top.si 페이지의 언어 버튼이 누를 때마다 한 → EN → 中으로 바뀌게 합니다.
  4. 머리말과 바닥글 문구에 중국어를 더합니다.
- **`main.js`가 바뀌기 전**: `landing.js`가 넘기는 세 번째 인자는 무시되므로, 화면은 지금과 같이 한·영으로 보입니다.
- **확인**: 중국어 화면에 한글이 남지 않았는지 검사합니다. 휴대폰 너비에서 중국어 제목의 줄 나눔도 확인합니다.
