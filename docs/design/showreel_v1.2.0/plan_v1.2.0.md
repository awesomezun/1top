## v1.1.1에서 바뀐 점

사용자가 말한 '쇼릴 5,6번'은 v1.0.0 화면의 05 / EVERYWHERE와 06 / LANGUAGE였습니다. v1.1.0·v1.1.1은 이를 계획서 순번(⑤ 메뉴 막대·트레이, ⑥ 휴대폰·웹)으로 잘못 읽어 메뉴 막대·트레이를 빼고 언어 장면을 남겼습니다. v1.2.0에서 바로잡았습니다.

## 확인한 것

- 04 / MENU BAR · TRAY의 메뉴 원본과 트레이 정지 화면은 `3e41fe5` 빌드(확인창 제거 커밋 이후)와 같은 demoNow 1800000000으로 다시 찍었습니다. 메뉴 패널(macOS)과 트레이 퀵뷰 코드는 `08748ca` 이후 바뀌지 않았습니다.
- 퀵뷰와 맥 패널, 메뉴 막대·작업 표시줄 아이콘 모두 공식 파형 마크입니다. 1시간에서 두 패널 모두 108M tokens/시간, 계정 한도 61%·33%·71%·18%입니다.
- 1,062프레임, 1920×1080, 30fps, 35.4초. MP4 3.6MB, WebM 3.2MB. 튀는 프레임이 없고 첫 프레임과 마지막 프레임이 같습니다.
- 랜딩 미리보기의 '35초 둘러보기'가 v1.2.0을 재생합니다.
