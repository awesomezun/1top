2026-10-31. 프론트 계기판 확정을 기다리는 동안 백엔드만 수정한 기록입니다. **이 변경은 아직 설치본·릴리스 초안에 반영하지 않았습니다.** 기반 커밋은 `f92f5cd`입니다.

## 확인한 오류와 변경

1. **Claude 네이티브 실행 파일의 버전 이름 때문에 프로필·GLM 탐색이 누락됨.** 실제 Mac에서 Claude 네이티브 프로세스 33개가 `2.1.x` 형태의 이름으로 실행 중이었습니다. 기존 이름 판별은 0개를 인식했고 실행 파일의 `claude/versions/<버전>` 경로를 포함한 판별은 33개를 인식했습니다. 그중 GLM endpoint 설정이 있는 프로세스는 3개였으며, 키를 중복 제거하면 GLM 소스 1개입니다. 이는 프로세스·설정 탐색 검사이며 API 재조회나 추가 세션 실행 결과가 아닙니다.
   - `discovery.cli_kind`의 선택 인자로 실행 파일 경로를 받고 계정·제공자 수집에도 같은 판별을 사용합니다.
   - npm으로 실행한 Claude/Codex의 별도 프로필도 찾습니다. 일반 Node 앱의 환경은 CLI 계정으로 간주하지 않습니다.
   - 키·환경·원본 명령행을 출력하거나 릴레이에 새로 보내지 않습니다. API 응답 구조와 계정 ID 계산은 유지합니다.
2. **HTTP 429의 Retry-After가 날짜일 때 너무 일찍 재조회함.** 기존 구현은 초 단위 숫자만 이해해 날짜형 10분 대기를 5분으로 처리했습니다. 날짜형도 읽도록 수정했고, 대기 중 추가 요청 없음·대기 종료 후 복구를 검사했습니다. 기존 최소 120초·최대 3600초 범위와 잘못된 값의 기본 300초 대기는 유지합니다.
3. **Linux 전체 CPU에서 I/O 대기·guest 시간이 과대 계산됨.** psutil의 counter 의미에 맞춰 I/O 대기는 유휴 시간으로, user/nice에 이미 포함된 guest 시간은 중복 제외합니다. 역행한 OS counter는 항목별로 0 처리합니다. macOS의 정상 카운터 결과와 전체 논리 코어 100% 기준은 유지합니다. Linux 결과는 합성 카운터 회귀 검사이며 Linux 실물 측정 결과가 아닙니다.
