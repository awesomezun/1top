# 4.4.0 최종 통합·공개 배포 순서 v1.0.0

2026-10-31. 사용자는 프론트엔드 수정 완료 뒤 백엔드 연결·마무리·배포,
그 이후 랜딩페이지·히어로 데모·쇼릴 업데이트를 지시했다.
이 지시는 최종본의 공개 배포 승인이다. 아직 수정 중인 프론트를 최종본으로 취급하지 않는다.

## 현재 준비 상태

- 백엔드 `687108c`: 종료된 세션 모델 집계, 로컬 API 및 원격 릴레이 전달 완료.
- Python 443개, cloud 81개 테스트 통과, 기존 벤치마크 1개 건너뜀. TypeScript 검사 통과.
- 새 산출물 번호: 제품 4.4.0, macOS·iOS build 10, Android versionCode 14, relay 1.12.0.
- frontend-freeze_v1.23.2는 v1.23.1에서 ios/project.yml 빌드 번호만 변경한 파생 목록이다.
- 프론트 최종 커밋·새 동결은 아직 미수신. 현재 수정 중인 화면을 조기 병합·설치하지 않는다.
- 이전 build 9 초안과 설치 파일은 보존한다. 새 파일은 별도 후보 폴더와 build 10 릴리스에 둔다.

## 실행 순서

1. 프론트가 완료로 인계한 커밋과 동결을 확인하고 통합한다. 현재 세션 목록 대신
   period_usage.windows[].by_model / snapshot.periods[].by_model 연결이 들어 있는지 확인한다.
   새 트레이 정적 파일이 있다면 서버와 Windows 패키지 경로를 연결한다.
2. 최종 소스의 Python·웹·릴레이·Swift·모바일 검사와 한국어 화면을 검증한다.
3. macOS DMG, iPhone 개발용 앱, Android APK·AAB, Windows EXE·MSIX를 빌드한다.
   각 산출물의 버전·소스 커밋·SHA-256을 새 manifest에 기록한다.
4. 사용자 Mac과 연결된 iPhone에 설치하고 실제 실행·연결을 확인한다.
   기존 데이터와 Keychain helper를 보존하며 사용한 테스트 기기만 종료한다.
5. 검증한 릴레이와 GitHub 릴리스를 배포하고 main release.json의 실제 다운로드·해시를 갱신한다.
6. 랜딩 담당 최종본을 받아 확정된 앱 화면과 배포 버전에 맞게 랜딩·히어로·쇼릴을 업데이트한다.
   기존 미디어는 보존하고 새 버전 경로를 사용한다. hero와 showreel의 기준 화면·데이터를 맞춘다.
7. 웹 /app과 랜딩을 배포하고 실제 주소의 기능·미디어·다운로드·버전 일치를 확인한다.

현재 확인한 최신 랜딩 작업 경로는 /Users/kang/orca/workspaces/1top/landing-v7.0.0 이며,
미커밋 미디어가 있으므로 이 상태를 인계 완료나 배포 가능한 최종본으로 간주하지 않는다.
