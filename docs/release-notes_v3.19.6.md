# 1top v3.19.6

Includes the adaptive burn-rate gauges, thin column resize handles, and compact Mac toolbar from [v3.19.5](release-notes_v3.19.5.md).

- The sidebar order is Dashboard, Account limits, Usage map, Computer resources, Goals · Loops · Skills, Measurements.
- Navigation icons use equal-width columns so every menu label, including Dashboard, begins at the same horizontal position. Selection changes the background without shifting the label.

The browser regression suite checks the final navigation order and equal label positions alongside mouse resizing, keyboard reordering, saved preferences, and theme/language transitions.
