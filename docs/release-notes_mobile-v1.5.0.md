# 1top mobile v1.5.0 — session inboxes

Session details now open with Messages and retain the existing Controls tab. Send a message, see queued or waiting status, and read only the session’s correlated answer. The current computer and session remain visible above the conversation. Working sessions still appear first.

A shared LAN is not required. The connected computer must remain online. Messages can consume provider tokens; a busy session may reply later. General work logs are not copied into the inbox. The relay forwards requested inbox content without storing its text.

Android APK/AAB are signed previews. iOS is a development build; App Store/TestFlight distribution is pending.
