# 1top mobile v1.2.0 preview

Usage now focuses on the token-share map. Context-map panels have been removed from Usage and session details. Period selection, session/app/tool/model grouping, small-area details, and existing session controls remain available. The built-in Codex Pro example shows its weekly window only.

The Android APK is signed with the existing project key. iOS device archive and private development export are built; no public iOS download is included. TestFlight/App Store distribution and physical-phone Google sign-in, reconnection, and remote-control validation remain pending.

Managed remote access still requires an approved account and existing device connection. Public pairing remains closed.
