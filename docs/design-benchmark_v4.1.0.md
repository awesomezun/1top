# 1top landing benchmark v4.1.0

Observed 2026-10-24 in a 1440 × 1000 browser viewport. These are visible frontend observations, not backend analysis. Reference brands and assets are not reused.

| Reference | Observed design | 1top application |
| --- | --- | --- |
| [T3 Code](https://t3.codes/) | Dark hero, visible square grid, floating app tiles, large centered type and a direct download action | Visible coordinate grid; original tiles representing apps, sessions, usage and limits; clear download/demo actions |
| [Linear](https://linear.app/) | Large readable headline followed immediately by a detailed product interface; restrained borders and secondary text | The actual desktop recording anchors the page; session information remains readable and separate from explanatory copy |
| [Raycast](https://www.raycast.com/) | Strong brand color, dimensional motion behind the hero and a clear download action | Mint, blue and amber distinguish monitoring surfaces; subtle tile motion and lit edges add depth |
| [Vercel](https://vercel.com/) | Public content was readable, but this browser redirected to login | No visual conclusion drawn from the login page; not used as visual evidence |

The three actual app recordings are independently displayed rather than hidden behind tabs. A pause button stops videos and decorative motion; reduced-motion preferences start them paused. The four-account panel uses synthetic personal/work identities and provider-reported percentage semantics. Mobile stacks the same sections without a separate feature set.

Preserved predecessor: `build/checkpoints/revision_v2.2.0_site_v4.0.0/`. Public media and capture scripts use `v4.1.0`; the prior `v4.0.0` media remain available. `scripts/showcase_v4.1.0/manifest.json` records production-source and media hashes.
