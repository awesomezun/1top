# 1top

여러 컴퓨터와 앱에서 실행되는 AI 에이전트를 한 화면에서 확인합니다.

[웹사이트](https://1top.si) · [설치 없이 체험](https://1top.si/app?demo=1) · [English](README.md)

현재는 초기 미리보기 단계입니다. 웹 체험은 설치 없이 사용할 수 있습니다. Mac 연결 앱은 로컬 빌드를 지원하며, 일반 사용자용 다운로드는 Apple 배포 서명·공증과 첫 실행 검증을 완료한 뒤 제공합니다. Windows·Linux 연결 앱은 아직 제공하지 않습니다.

## 사용 흐름

모니터링할 Mac에서 **연결 앱 다운로드 → 실행 → Google 로그인**을 한 번 진행합니다. 연결 앱은 메뉴 막대에 남아 동작하며, 선택적으로 로그인 시 자동 실행을 켤 수 있습니다. 조회하는 휴대폰이나 다른 컴퓨터에서는 웹 로그인만 하면 됩니다.

브라우저 로그인만으로 로컬 프로그램의 실행 정보·토큰 기록을 읽거나 중단할 수 없어, 모니터링할 컴퓨터에는 연결 앱이 필요합니다.

## 확인할 수 있는 정보

- 어떤 컴퓨터·앱·터미널에서 어떤 세션이 실행 중인지
- 24시간·12시간·5시간·1시간·30분·10분의 기록된 토큰 사용량
- 최근 최대 60초의 평균 사용 속도와 CPU·메모리
- 지원되는 세션의 바로가기·작업 중단·재개·CLI 종료

도구별 지원 범위가 다릅니다. 토큰 기록을 확인하지 못한 값은 0 대신 미확인으로 표시합니다. 앱 감지가 해당 앱 내부 AI 사용량 수집을 뜻하지는 않습니다. 현재 여러 앱의 실행 위치를 감지하지만, 작업 중단·재개는 검증된 제어 어댑터가 있는 세션에서만 활성화됩니다.

전체 합계는 현재 보고 중인 기기만 포함합니다. 오프라인 기기는 마지막 보고 시간과 함께 표시됩니다. 이 수치는 제공자가 보고한 토큰이며 청구 금액이나 구독 잔여 한도가 아닙니다.

## 데이터와 원격 제어

대화 원문·전체 파일 경로·환경 변수·제공자 API 키를 클라우드 전송 항목에서 제외합니다. 기기·프로젝트 이름, 토큰 합계, 자원 정보 등은 본인 계정의 대시보드로 전송됩니다. 이름에도 사적인 정보가 담길 수 있습니다.

원격 명령은 선택한 기기와 세션에만 전달하며, 오래된 상태나 잘못된 식별자에는 실행하지 않습니다. 오프라인 명령을 나중에 재생하지 않으며 중복 요청을 차단합니다. 원격 바로가기는 해당 컴퓨터의 앱을 앞으로 가져오는 기능으로, 화면 공유는 아닙니다.
