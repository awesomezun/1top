# 1top v3.0.1 — desktop preview

1top shows local AI sessions, the apps and terminals hosting them, token totals and recent usage, subscription limits when reported, and computer resources. Local monitoring is free and works without a 1top account.

## Downloads

- [macOS DMG — Apple silicon, macOS 13+](https://github.com/awesomezun/1top/releases/download/v3.0.1/1top-3.0.1-macos-arm64.dmg)
- [Windows installer — x64, Windows 10/11](https://github.com/awesomezun/1top/releases/download/v3.0.1/1top-3.0.1-windows-x64-setup.exe)
- [SHA-256 checksums](https://github.com/awesomezun/1top/releases/download/v3.0.1/SHA256SUMS.txt)

These are preview installers. The macOS build is ad-hoc signed and not Apple-notarized; the Windows installer has no publisher certificate. The OS may show a security prompt or block first launch. Windows requires the Microsoft Edge WebView2 runtime. Do not treat these artifacts as a signed production release.

On macOS, open the DMG and drag 1top to Applications. The app opens a menu-bar panel and a full desktop dashboard. On Windows, run the installer, then open 1top from Start; closing the dashboard keeps its tray process running.

## Changes

- Windows desktop window, tray, per-user installer and local collection.
- Session-to-process identity checks on Windows; token data is attached only when its session log is identified. Unreported usage stays unknown.
- Usage maps hide labels that cannot fit and show complete names, exact token counts and session details on hover/focus.
- Original waveform branding across app icons and the website.

Windows session control currently offers only verified capabilities. Pause/resume are not offered without an adapter. App focus brings a window forward on that computer. CLI termination targets the selected process after checking its identity.

## Validation

- Windows CI installed the actual installer, started its packaged collector and WebView dashboard, and checked session usage, context input and host resources against a controlled fixture.
- Mac build and disk-image checksum verification completed; the installed app served v3.0.1 locally.
- Python checks and shared map checks passed. Source and Windows builds remain reproducible through scripts and GitHub Actions.

Optional managed remote access remains limited to approved accounts. Public enrollment and paid checkout are not enabled. This release does not claim support for every application's private token format or for WSL process inspection.
