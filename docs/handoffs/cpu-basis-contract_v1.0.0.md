# CPU 표시 기준 v1.0.0

4.4.0 사용자 추가 요청: 프로세스와 세션의 CPU도 컴퓨터 전체의 논리 코어 합계를 100%로 표시합니다.

- `system.cpu_basis: "host_total"`을 추가합니다. Python 원격 내보내기와 relay 허용 목록도 이를 보존합니다.
- `system.top[].cpu`, `system.shared[].cpu`, `system.monitor.cpu`, 로컬 `sessions[].resources.cpu`, 원격 `sessions[].cpu`는 모두 **이미 전체 코어 기준으로 나눈 퍼센트**입니다. 프론트에서 다시 나누지 않습니다.
- `system.host.cpu`, 원격 `host.cpu`, `system.history[].cpu`는 기존부터 전체 CPU 기준입니다. 변경하거나 다시 나누지 않습니다.
- 계산: CPU 사용 시간 증가 / 관측 경과 시간 / 논리 코어 수 × 100. 예: 16코어에서 코어 하나를 계속 사용하면 6.25%, 두 개면 12.5%입니다. 첫 관측·리셋 등 측정 불가 값은 계속 null입니다.
- 구버전 수집기는 프로세스·세션·수집기 CPU를 코어 하나 기준으로 보냅니다. 기존 수집기에는 `cpu_basis` 필드가 없습니다. 필드가 없다는 이유만으로 4.4.0 수치를 다시 나누면 안 됩니다. 이전 relay가 새 필드만 제거할 수 있으므로 수집기 `version >= 4.4.0`도 전체 기준의 근거가 됩니다.
- 과거 벤치마크 자료는 이번 수집 계산 변경의 대상이 아닙니다. 해당 자료에 전체 코어 기준이라고 새로 이름을 붙이면 안 됩니다. 변환하려면 그 표본의 코어 수와 기존 계산 기준이 확인돼야 합니다.

백엔드 검증: 16코어에서 부모 프로세스 1코어·자식 2코어 사용을 모의해 각각 6.25%·12.5% 및 세션 합계를 확인했습니다. 같은 표본의 전체 CPU·추이 값 50%는 그대로이며, relay 경유 시 두 번 나누지 않는 것도 검사합니다.
