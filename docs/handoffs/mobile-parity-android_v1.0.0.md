# Android 앱 기능 대조와 복구 v1.0.0

작성일: 2026-10-29
범위: `mobile/` Expo 앱(Android). iOS 네이티브 앱은 별도 문서에서 다룹니다.
비교 기준: mobile v1.5.0입니다. 대시보드 탭을 추가한 `99a2be6` 바로 앞 커밋(`99a2be6~1`)이 이 상태입니다.

## 누락 원인

`99a2be6`에서 맥 메뉴바 간략보기를 옮긴 대시보드를 첫 탭으로 넣고, 기존 세션 화면은 두 번째 탭으로 옮겼습니다.

기존 기능의 코드와 탭은 모두 남아 있었습니다. 문제는 앱을 열면 처음 보이는 대시보드 쪽이었습니다.

**진입 경로가 없던 기능**

- 세션 행을 눌러도 메시지함·작업 제어·AI 지시로 들어갈 수 없었습니다.
- 컴퓨터를 고르는 방법이 없었습니다.
- 연결이 끊겼을 때 다시 연결하는 버튼과 마지막 보고 시각이 없었습니다.
- 원격 명령 결과 알림도 표시되지 않았습니다.

**잘못 집계하던 값**

- 흐름, 계정 한도, CPU·메모리를 첫 번째 컴퓨터 것만 읽었습니다.
- 기간 합계를 `null`로 고정해 두어, 이미 끝난 세션의 사용량이 평균 속도에서 빠졌습니다.

**기존 탭에 원래 있던 문제**

- 세션 탭의 속도는 `tok/s`로 표시했습니다.
- 버전 표시는 `v1.2.0`으로 하드코딩돼 있었습니다.

저는 화면 모양만 대조했고, v1.5.0의 기능 목록과 하나씩 맞춰 보지 않았습니다. 그래서 이 누락을 놓쳤습니다.

## 바꾼 파일

- `mobile/src/fleet.ts` (새 파일): 모든 컴퓨터 집계, 기간 합계, 흐름 합산, 한도 중복 제거, 추정치 판정, 시간당 평균, 숫자 표기
- `mobile/src/state-mark.tsx` (새 파일): 작업 상태 모양
- `mobile/src/dashboard.tsx`: 집계 규칙 적용, 컴퓨터 선택, 알림, 재연결, 행을 눌러 상세 열기, 경과 시간, 액정 초록, 상태 모양

- `mobile/src/types.ts`: `snapshot.periods` 타입
- `mobile/src/demo.ts`: 체험용 두 번째 컴퓨터를 추가했습니다. 오래된 한도 하나, 확인 필요 세션 하나, 일시정지 세션 하나가 들어 있습니다.

## 남은 일

- Android 실기기 확인이 필요합니다. APK·AAB 빌드는 Codex가 맡습니다. 원격 명령 확인 대화상자와 실제 전송·receipt는 웹 미리보기로 검증할 수 없어서 실기기에서 확인해야 합니다.
- `app.json`은 아직 `version 1.5.0`, `versionCode 8`입니다. 4.0.0 / 9로 올릴 때는 이 파일을 바꾸면 화면의 버전 표시도 함께 바뀝니다.
- 세션 탭과 상세에서 GLM 세션의 실행 도구가 `Claude Code`로 표시됩니다. `metrics.tool`이 원래 이렇게 매핑하고 있으며, 이번 범위 밖이라 그대로 두었습니다.
- 대시보드에서 하위 세션이 있는 행을 누르면 루트 세션 상세가 열립니다. 하위 세션 각각은 세션 탭에서 엽니다.
