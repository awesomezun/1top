## 2. 바뀐 것 (사용자 요청: "답신 이런 구닥다리말고 요즘 에이전트 채팅앱처럼")

데스크톱·웹, 아이폰, 안드로이드 네 화면이 같게 바뀌었습니다.

- AI 메시지는 '세션의 답신' 머리말 없이, 종류 색 아이콘과 이름(예: Claude Code)이 붙은 말풍선으로 나옵니다.
- 보낸 메시지 아래에는 작은 상태만 둡니다. AI 메시지가 오면 이 표시는 사라집니다.

  | 상태 값 | 한국어 표시 |
  |---|---|
  | queued | 차례 기다리는 중 |
  | sending | 보내는 중 |
  | delivered·awaiting_reply | ✓ 보냄 |
  | delivery_unconfirmed | 확인 안 됨 |
  | source_changed | 세션이 바뀜 |
  | not_delivered | 보내지 못함 + 다시 시도 |

- 계약(mobile-conversation-contract)의 상태 값과 데이터 모양은 바꾸지 않았고, 표시만 바꿨습니다.
- 대화 화면 밖의 데스크톱·웹 화면은 바뀌지 않았습니다.

## 3. 백엔드에 부탁드릴 문구 하나

`agent/onetop/controls.py`의 오류 문장 '이 세션의 답신 연결을 확인하지 못했습니다. 메시지를 전송하지 않았습니다.'를 아래 문장으로 바꿔 주세요.

> 이 세션과의 대화 연결을 확인하지 못했습니다. 메시지를 보내지 않았습니다.

`i18n.js`에는 새 문장과 예전 문장의 영어·중국어를 모두 넣어 두었습니다. 그래서 바꾸기 전후 어느 쪽이든 번역되고, `tests/i18n-collector.mjs`도 통과합니다.
